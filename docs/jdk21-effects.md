# Java 21 effects and ownership by package

Generated from the reviewed Java annotations and catalog evidence. Counts cover the same API entries as [the coverage inventory](jdk21-coverage.md). Every package is listed; a zero means no stronger footprint is supplied, not that the package is pure. The [machine-readable ledger](../specifications/jdk21/effects.json) records each declared summary, parameter/result ownership, view relationship and review rationale.

`@Modifies({})` preserves existing storage on normal and exceptional exits. Nonempty footprints name possible writes; `@Free` separately describes fresh results. `@ReturnsView` derives ownership from a captured backing List. Entries without a footprint retain conservative effects, even when they have scalar refinements. Read-only concurrent observations remain snapshots. See [the annotation semantics](external-refinements.md) and [review boundaries](jdk21-contracts.md#effect-and-ownership-review).
