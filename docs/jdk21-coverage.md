# Java 21 package coverage

All 178 Java SE 21 packages are selectable. Every documented type and public/protected member has an explicit policy, directly or through its indexed ancestors. The catalog includes the official all-classes index and recursively discovered public/protected member classes, which that index does not exhaustively list. Counts below include declared members, explicit inherited refinements, and members exposed by non-API ancestors; ordinary inherited members are counted at their declaration.

**Complete coverage means exhaustive classification, not a precise behavioral refinement of every member.** The 501 reviewed declarations have stronger source contracts. All other entries use conservative unknown-call or field handling, without ownership, purity, value or state promises. No manual implementation review is claimed for conservative entries. See the [policy, limitations and regeneration instructions](jdk21-contracts.md).
